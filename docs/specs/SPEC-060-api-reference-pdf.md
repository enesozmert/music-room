# The OpenAPI document is also a reference somebody can read

## Goal

`make openapi` produces `docs/api/API-REFERENCE.md` beside `docs/api/openapi.json`, `docs/build-pdf.sh`
renders it to PDF with every other distribution artifact, and `make agent-check` fails if either has
drifted from the code.

## Out of scope

- **Hand-written prose in the generated file.** Anything worth arguing belongs in `ENDPOINTS.md`.
- **Serving Swagger outside Development.** Unchanged: the interactive UI stays a development tool.
- **A second format.** Markdown renders to PDF through the pipeline that already exists.

## Decisions

| # | Decision | Why, and what was rejected |
|---|---|---|
| 1 | **Generated by `make openapi`, not by `build-pdf.sh`.** | The Markdown is derived from the document, and the document is derived from the code. Putting the generation in the renderer would mean a PDF build could change a tracked `.md`, which is the kind of surprise that makes people stop trusting a build |
| 2 | **The drift check covers the Markdown too.** | `git diff --exit-code -- docs/api/openapi.json docs/api/API-REFERENCE.md`. A generated file nobody checks is a file that is wrong six weeks later |
| 3 | **Deterministic output, in the document's own order.** | A generator that sorted differently on two machines would make the drift check a coin toss |
| 4 | **Nullable `anyOf` members are collapsed to "or null".** | The generator renders for a reader. `anyOf: [string, null]` is a type and a footnote, not two types |

## Files

| Path | Action |
|---|---|
| `scripts/openapi-markdown.py` | create — the generator |
| `docs/api/API-REFERENCE.md`, `docs/api/API-REFERENCE.pdf` | create — generated, committed |
| `Makefile` | change — `openapi` generates it, `agent-check` guards it |
| `docs/build-pdf.sh` | change — renders it |
| `docs/specs/SPEC-060-api-reference-pdf.md` | create |

## Verification

| Check | Proves |
|---|---|
| `make openapi` twice | the second run changes nothing — the output is deterministic |
| the rendered PDF | every route in the document appears, with its parameters, body and answers |
| a route added without regenerating | `make agent-check` fails on the drift check |
| the live document against the committed one | identical but for `servers`, which only a running host can know |
